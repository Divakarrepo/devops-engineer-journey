## What I Learned

### 1. What is the DevOps Lifecycle?

The DevOps lifecycle is a continuous process used to develop, deliver, deploy, monitor, and improve software.

The typical DevOps lifecycle includes:

```text
Plan
  ↓
Code
  ↓
Build
  ↓
Test
  ↓
Release
  ↓
Deploy
  ↓
Operate
  ↓
Monitor
  ↓
Feedback
  ↓
Plan again

```
### 2. Steps Followed in DevOps

The major stages I learned are:

- Plan — Understand requirements and plan the work.
- Code — Developers write and manage application code.
- Build — Source code is compiled or packaged into a deployable application.
- Test — The application is tested to identify defects.
- Release — A tested version is prepared for deployment.
- Deploy — The application is deployed to an environment.
- Operate — The application and infrastructure are maintained.
- Monitor — Application and infrastructure performance are monitored.
- Feedback — Monitoring and user feedback are used to improve the next development cycle.

### 3. What is a Computer?

A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information, and produces output.

```
Input
  ↓
Processing
  ↓
Output
  ↓
Storage
```

### 4. Components of a Computer

The major components I learned are:

- CPU — Central Processing Unit

The CPU processes instructions and performs calculations.

It is commonly described through:

- ALU — Arithmetic Logic Unit
- Control Unit
- Registers
- RAM — Random Access Memory

RAM temporarily stores data and programs that are currently being used.

It is volatile memory, meaning its contents are lost when the system is powered off.

Storage

Storage is used to permanently store data and applications.

Examples:

- HDD
- SSD
- Motherboard

The motherboard connects the major hardware components and allows them to communicate with each other.

Input Devices

Examples:

- Keyboard
- Mouse
- Microphone
- Output Devices

Examples:

- Monitor
- Printer
- Speakers
